# 人体のしくみ

心臓は何をする？食べ物はどこを通る？からだの34の器官や血液の成分のはたらき・仲間・読み方、歯の数や血液の量などのからだの数、食べ物・血液・尿の通る順番を、4つから選んで当てる1日5問のゲーム。知らなくても遊べます。押すだけ、時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/jintai-shikumi/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（まちがえても続く・一発で何問当てられるか）、解いた種類が集まる「からだ帳」があります。
- 問題は「はたらきから」「どの仲間」「読み方」「仲間さがし」「はたらきを選ぶ」「書き方」「次はどこ」「仲間はずれ」「同じ仲間から」「からだの数」「通る順」「正しい組み合わせ」。正解すると、器官の札（読み・仲間・はたらき）と「なぜ」と出典が出ます。
- 問題は557問（12種類）。チケット・回数制限はありません。
- 文字の大きさは3段から選べます。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）もあります。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

このゲームは、からだのしくみを知るためのものです。病気・けが・体調の相談には使えません。気になることは医師にたずねてください。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：画面を開くと文字（Google Fonts）のために Google へつなぐので、文字が端末に保存済みでも Google に IP アドレスが届くことがあります。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
